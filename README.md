# Шкільний автобус

Додаток для відмітки посадки й висадки дітей. Збирається в APK автоматично на GitHub.

1. На github.com натисніть «+» → New repository. Назва: shkilnyi-avtobus. Виберіть **Private**. Create repository.
2. Розпакуйте цей архів. На сторінці репозиторію натисніть «uploading an existing file» і перетягніть усе з розпакованої папки (папки .github, www, tools, assets і файли). Натисніть Commit changes.
3. Відкрийте вкладку Actions. Збірка «Build APK» стартує сама (5–10 хвилин). Якщо ні, виберіть Build APK → Run workflow.
4. Коли з'явиться зелена галочка, відкрийте цей запуск. Внизу в розділі Artifacts завантажте shkilnyi-avtobus-apk. Усередині архіву файл app-debug.apk.
5. Перекиньте app-debug.apk на телефон і встановіть його (дозвольте встановлення з цього джерела).

Якщо збірка позначилась червоним хрестиком, скопіюйте текст помилки з кроку, що впав, і надішліть його Claude.
